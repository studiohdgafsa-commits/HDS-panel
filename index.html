الاتصال بـ GitHub

لم يُحفظ رمز GitHub بعد، ولا يمكنك الحفظ والنشر قبل إضافته:
  1. افتح github.com ثم Settings ثم Developer settings ثم Fine-grained tokens ثم Generate new token.
  2. في Repository access اختر Only select repositories ثم HDS-panel.
  3. في Permissions اختر Contents ثم Read and write.
  4. انسخ الرمز والصقه هنا.

يُحفظ الرمز مشفّراً في هذا المتصفح فقط.
